# MCP 工具(按需加载)

本会话启用的 **MCP 工具**默认**不会**出现在你的工具列表里(为节省上下文)。需要调用外部 MCP 工具时:

1. **先读取本技能**(`/skills/mcp/SKILL.md`)——读取后,本会话已启用的 MCP 工具才会被提供给你;
2. 然后按工具名正常调用;
3. 若读完仍**没有出现任何 MCP 工具**,说明本会话没有启用 MCP(或配置为空):**不要臆造工具**,直接告诉用户当前没有可用的 MCP 工具,并建议其在会话里勾选/由管理员配置。

> 注意:如果对话被**自动压缩**(上下文过长时的历史摘要),这段"读取技能"可能被摘要替换,届时 MCP 工具可能再次不可见;需要时**重新读取本技能**即可。
