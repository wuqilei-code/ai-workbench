# HTML 报告(html-report)

创建自包含 HTML(单文件、内嵌 CSS/JS/图表),零外部依赖、可离线打开。
环境:纯文件生成,不需要额外库;图表用内嵌 ECharts/纯 SVG。交付用 `[结果文件] <相对路径>`。

## 工作流程
1. **先规划**(写 HTML 前输出):
   - 类型/主题/受众/语言(用用户语言);
   - 设计系统:`--bg --bg2 --ink --muted --rule --accent --accent2` + 字体 + 布局;
   - 章节结构;视觉元素(图表/图示/插图)。
2. **写内容**:证据驱动,清晰 H2/H3 层级,专业语气。
3. **做图**:数据图表用 ECharts(内嵌)或内联 SVG;结构图用 SVG/纯 HTML;不要外链 CDN。
4. **构建**:单文件 `<report>.html`,内嵌 `<style>` 与 `<script>`,自包含。

## 输出路径
报告文件必须保存到 `reports/` 目录。生成前先 `mkdir -p reports`。
交付路径格式:`[结果文件] reports/报告名.html`。

## 规范
- 文件头注释:`<!-- Generated by AI Workbench -->`
- 禁止:绝对本地路径、`file://`、远程 URL、Base64 大数据(图片用 SVG 内联或按需)。
- 响应式:`.wrap{max-width:1000px;margin:auto}` + `@media print` 样式;正文 ≥14px。
- 配色从 CSS 变量取,图表颜色与主题一致,禁彩虹色/硬编码十六进制。

## 模板骨架
```html
<!DOCTYPE html><html lang="zh"><head><meta charset="utf-8">
<meta name="viewport" content="width=device-width,initial-scale=1">
<title>报告标题</title>
<style>
:root{--bg:#0f172a;--ink:#e2e8f0;--muted:#94a3b8;--rule:#1e293b;--accent:#38bdf8;--accent2:#a78bfa}
*{box-sizing:border-box}
body{margin:0;background:var(--bg);color:var(--ink);font-family:"Segoe UI","Microsoft YaHei",sans-serif;line-height:1.7}
.wrap{max-width:1000px;margin:0 auto;padding:48px 24px}
h1{font-size:34px;margin:0 0 8px}h2{font-size:24px;border-bottom:1px solid var(--rule);padding-bottom:6px;margin-top:40px}
h3{font-size:18px;color:var(--accent)}
.card{background:rgba(255,255,255,.04);border:1px solid var(--rule);border-radius:12px;padding:16px 18px;margin:12px 0}
table{width:100%;border-collapse:collapse;margin:16px 0}
th,td{border:1px solid var(--rule);padding:8px 10px;text-align:left;font-size:14px}
th{color:var(--accent)}
@media print{body{background:#fff;color:#000}}
</style></head><body><div class="wrap">
<h1>标题</h1><p style="color:var(--muted)">副标题 / 日期 / 作者</p>
<h2>章节</h2><p>正文</p>
<div class="card"><strong>关键结论</strong><br>…</div>
<h2>数据</h2>
<svg viewBox="0 0 400 40" width="100%" height="40"><rect x="0" y="0" width="120" height="40" fill="var(--accent)"/><text x="150" y="26" fill="var(--ink)">120</text></svg>
</div></body></html>
```

## ECharts(可选,内嵌)
```html
<script src="https://cdn.jsdelivr.net/npm/echarts@5/dist/echarts.min.js"></script>
```
**优先内联 SVG / 简表**,确需图表时用上/下 ECharts(自包含原则下可把 echarts 代码离线内联或改纯 SVG)。

## 完成后
- 交付 `[结果文件] reports/<report>.html`;若有配套资源给出路径一并交付。
